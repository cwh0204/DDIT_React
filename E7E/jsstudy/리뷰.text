Node 설치 => NVM(Node Version Manager) => 멀티 버젼 설치
          => Node 설치하면 => JS를 OS위에서 실행 가능
          => JRE이 비교될 수 있음, JS 인터프리터 방식

NPM => Node Package Manager => Maven 빌더에 비유될 수 있음
       필요한 모듈 설치/삭제를 편하게 해줌
       Node를 설치하면 자동으로 같이 설치됨
       Package.json에 설치한 모듈이 dependency로 등록됨
       Package-lock.json 파일은 설치한 모듈의 개별 버젼정보를 가짐
       Package.json 파일의 script에 명령어 등록가능
                start/test만 run 생략가능 npm start/npm run start 생략가능
        모듈 검색은 어디서 npmjs => maven reository
        배포시 node_modules 폴더는 주지 않는다(용량만 크다)
        
webserver 만듬 => express 이용 => Spring으로 하기 때문에 그리 중요하지 않다

원시타입 string number boolean          => 복사
객체타입 원시타입 아닌 거 전부 (function도 객체)      => 참조(별명)

var (생명의 경계선 function키워드) vs let/const ( {} 기호가 생명의 경계선)
const 주의 사항 : 객체 타입인 경우 속성과 메소드 곧 내용물은 바꿀수 있음

Wrapper(랩퍼) 불편한 원시타입을 편하게 쓰게 해주는 것
    string => String, number => Number, boolean => Boolean
